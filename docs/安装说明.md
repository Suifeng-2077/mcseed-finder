---
  快速安装指南（新手从这里开始）
---

只需要装一个东西：Node.js。


### 第1步：装 Node.js
  打开 https://nodejs.org
  下载 LTS（长期支持）版，Windows 选 .msi 安装包
  一路"下一步"装完。

  验证是否装好：
    按 Win+R，输入 cmd 回车
    输入  node -v  回车
    若显示 v20 或更高的版本号（如 v20.x.x），说明装好了。
    若提示"不是内部或外部命令"，说明没装上，重装一次。


### 第2步：解压本文件夹
  把整个 mcseed-pack 解压到任意位置，例如 D:\mcseed。
  （解压后能看到 mcseed-app 文件夹和 config.json）


### 第3步：开始用
  先打开你的 Minecraft 1.16.1 + mcsrfairplay 整合包，进入游戏。
  然后双击 mcseed-app 里的：
    start-next.bat  → 等待新世界模式（推荐，最直观）
    start-watch.bat → 后台实时监听
    start-now.bat   → 立刻取当前世界

  详见"使用说明.md"。

一句话总结：
  装 Node.js → 解压 → 先开游戏 → 双击脚本 → 看到 seed
