---
  Minecraft 1.16.1 Seed 捕获器 — 使用说明（先读这个）
---

这是一套在你本地电脑运行的命令行小工具，用来在你创建/重置新的
Minecraft 世界时，立刻告诉你这个世界（level）的种子 seed。

它完全不依赖 DeepSeek Harness 或任何在线服务，全在你自己的电脑上跑，
可以打包发给任何人用。

## 一、你需要准备什么（版本要求，务必核对）
1. Node.js  (必须，程序本体是 Node 脚本)
     下载: https://nodejs.org 选 LTS 版本，一路"下一步"安装
     验证: 打开 cmd 输入 `node -v`，能显示版本号即装好

2. Minecraft 1.16.1 + mcsrfairplay 整合包
     程序只适配这一个组合。整合包版本不一样，解密会失效，seed 读不出来。
     （当前适配：MC 1.16.1 + mcsrfairplay 1.2.1）

3. JDK（一般不需要）
     程序本身是 Node 脚本 + 已编译的 HuntKey.exe（独立程序），不需要 JDK。
     只有当"游戏运行中取加密世界 seed"需要找游戏进程时，会尝试用 jps
     （若你的电脑装了 JDK 才有 jps）；没有 jps 时程序会用 PowerShell 找进程，
     也能工作。所以大多数情况你不用额外装 JDK。


## 二、安装步骤
1. 装好 Node.js（见上）
2. 把整个 mcseed-pack 文件夹解压到任意位置，比如 D:\mcseed
   （解压后应看到：mcseed-app 文件夹、config.json、使用说明.md、安装说明.md 等）
3. 完成。不需要任何额外的"安装"。

## 三、三种用法（顺序：先开游戏，再开工具）
先启动你的 MC 整合包并进入游戏。

方法A - 推荐：等待新世界模式
  双击 start-next.bat
    1) 在游戏里重置/创建新世界
    2) 回到这个 cmd 窗口，按一下 Enter
    3) 窗口立刻显示新世界的 seed
    4) 不满意？再重置一次，再按 Enter，看下一个 … 循环用

方法B - 后台监听（实时）
  双击 start-watch.bat
    cmd 窗口会一直实时显示每个新世界的 seed，捕获时响一声。
    关闭窗口即停止。

方法C - 立刻取当前世界
  双击 start-now.bat
    立刻显示最近创建/修改的那个世界的 seed。

补充：命令行用法（双击脚本其实就是在执行这些）
    cd 到 mcseed-app 目录后：
      node mcseed-app.js watch   后台监听
      node mcseed-app.js next    等待新世界模式
      node mcseed-app.js now     立刻取当前世界
      node mcseed-app.js show    查看最近 10 条捕获记录

## 四、它怎么找到你的存档（自动检测，一般不用配置）
程序启动时会自动：
  - 找到正在运行的 Minecraft 游戏（javaw 进程）
  - 从游戏命令行推导出存档目录（MultiMC、原版启动器都支持）
  - 复用游戏同一个 JDK 的 jps 工具找游戏进程
所以：先开游戏，再开工具，通常开箱即用。

万一检测不到（游戏没开 / 启动器很特殊），手动编辑 config.json：
  savesDir   → 你的存档目录（...\.minecraft\saves）
  beep       → true/false  捕获时是否响一声
  autoHeap   → true/false  watch 模式遇到加密世界是否也自动内存扫描提取
  heapCooldownMs → 两次自动内存提取的最小间隔（毫秒）

## 五、seed 是怎么取出来的（原理，简单版）
程序按优先级尝试三种方式，哪个能用用哪个：
  1. plain 明文直读：level.dat 是明文 gzip，直接解出 seed（最常见，最干净）
  2. enc  密钥文件解密：读 worldDataKey.txt 解出密钥，再解 level.dat
  3. hunt 零痕迹内存扫描：加密且无密钥文件时，从游戏进程外读内存（ReadProcessMemory）
     找到世界密钥并解密 level.dat（需要游戏正在运行，通常 1 秒内完成，且不在游戏日志留痕迹）
看捕获记录的"方式"列（plain/enc/hunt）就知道用了哪种。


## 六、日志
默认日志文件：mcseed-app\seeds.log
格式：时间  类型  方式  世界名  LevelName  seed
（若 config.json 里配了 logPath，则以那个为准）
